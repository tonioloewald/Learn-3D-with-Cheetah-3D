# Content review against Cheetah 3D 8.1.1 (2026-10-27)

The whole book (127 pages) was reviewed against two sources:
- the **Cheetah 3D 8.1.1 in-app manual** (`/Applications/Cheetah3D.app/Contents/Resources/en.lproj/Cheetah3Dmanual/`), checked where it is silent against the app bundle itself (Localizable.strings, material node XML, bundled materials, Info.plist);
- the **scripting KB** (`~/cheetah3d-script-kb`).

Typos were fixed in place (see the end of this file). Everything below is a suggestion for the author. "Verify" marks a finding the sources couldn't settle; check those in the app.

## The big picture

The modeling, node-material, animation and conceptual material mostly still holds for 8.1.1. The problem is the **rendering and lighting setup**, which is written for v5/v6 throughout. It appears in about 20 pages, including the two flagship tutorials, so a reader following them in 8.1.1 gets stuck.

### Things 8.x has that the book doesn't cover
- **Falcon**: samples and bounces, Filmic tone mapping, reflective caustics, MIS, motion blur. 10.12 has empty "Falcon vs. Cheetah" / "Lights in Falcon" stub headings.
- **PBR material**, with Metalness, Roughness, Anisotropy and Clearcoat. Add Material › "Material (PBR)". It covers what 10.6 says needs Metal/Car Paint. Also the 3D view's PBR shading.
- **Normal maps**: every shader node has a Bump type (height / normal Y+ / normal Y−).
- New objects and tools:
  - Modeling: **Loft** creator, **Boolean modifier** and Boolean Add/Subtract/Intersect tools, **Simplify**, **Brush** tool (and soft selection), **Insert Point**, Mirror tool, Crumple/Smooth modifiers.
  - Primitives: Capsule and Fractal.
  - Subdivision: the **Stam-Loop** and Linear schemes.
- Rigging and animation: **Orient Joint** tool, **Spline IK**, Point/Orient/Parent **constraint tags**, Split Joint. Also the **Take Manager** (merge/split/reverse/Bake IK), Key Editor, and dynamics **initial state / cache / bake**.
- File formats: **glTF/GLB, USDZ**, STL, SceneKit .scn, DXF; EXR. Animation export is no longer FBX-only.
- System requirements: **macOS 10.15+, Apple Silicon native**, Metal viewport.

## Factual errors (wrong regardless of version)

- **10.11:** the State node outputs **I•N**, not I•R (three places). Also "1 − dot product = |I×R|" is false: |I×N| = sin θ = √(1−cos²θ), not 1 − cos θ.
- **10.9:** π/180 = 0.017453, not 0.017459.
- **10.1:** the caption says greater specular size makes a "smaller and duller" highlight. It should be "sharper", which matches the text below it and 10.8. "less-polished looking marble" in the wood section should say wood.
- **4.1:** the path tracer is described as emitting photons from lights. Falcon traces paths from the camera ("Samples: the number of paths traced per pixel").
- **10.8:** Gouraud and Phong *shading* are interpolation methods. The diffuse term is Lambertian, and Phong's reflection model adds the specular term.
- **15.3:** "Set the Rigid Body's margin to 0.0". The manual says the margin should never be zero.
- **15.4:** "a soft body tag on an object with too many **tags**" should be **points** (10,000 limit).
- **16.1:** 1 m = 39.37 **inches**, not feet (’).
- **12.4:** the Nikon D5000 is a **DX** camera, not FX.
- **18.4:** "lossy compression does not support alpha" contradicts the section's own ProRes 4444 recommendation.
- **8.10:** "If a **mesh** operates on its first two children" should be "creator".
- **8.11:** "the boolean chain creator" should be "the chain creator".
- **8.2:** Skeleton **modifier** should be Skeleton **tag**.
- **8.1:** the blueprint summary says "bottom" twice and contradicts the caption.
- **8.3:** the Ring Select tip says "(when in Loop Select mode)".
- **7.2:** "create four new materials" then names three.
- **13.1:** "IK is implemented by adding constraint tags". It's the **IK Handle** tag; IK Constraints only limit rotation.
- **18.1:** "Normal Utilities" script should be **Surface Utilities** (as in 17.8).
- **2.1:** CNC milling is subtractive, not 3D printing (author's voice; optional).

## 17.8 Scripts

- **Point readers at the scripting KB and AI-assisted scripting**: "Read https://raw.githubusercontent.com/tonioloewald/c3d-scripting-kb/main/dist/c3d-context-short.md and follow it" and the catalog. That is the biggest single improvement to this chapter, and it replaces the "you're on your own" framing.
- **Tools › Script › Update Menu** picks up new scripts without a relaunch.
- **Tag scripts** are per-frame expression tags (`performExpression(tag)`) since 7.0. The "only buildUI → Tag" heuristic and 17.6's description are out of date.
- In the target()/describe() samples, `doc.selectedObject()` returns the root (not null) when nothing is selected, so "Selection Only" acts on the whole scene. `doc.selectedObjects()` exists in 8.1.1. The Tool samples don't call `recordParametersForUndo()`.
- **Verify:** 8.1.1 has a "Script" layout view (`layoutScriptIDE`), possibly an in-app editor.
- **Every forum link uses the dead vBulletin format.** The current form is `https://www.cheetah3d.com/forum/index.php?threads/<id>/`. The master list (p=42637) is thread 5752. Same for 14_Character_Animation's link.
